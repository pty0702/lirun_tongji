# 利润统计工具 v2.2

本地 Excel 利润统计工具，读取订单表和成本表，按商品ID和商家编码计算利润，输出统计结果 Excel。

## v2.2 更新

- **多订单表分店铺输出**：多个订单表时，每个店铺独立输出明细/汇总/异常 sheet，额外提供总计合并 sheet
- 单订单表时保持原有 4-sheet 结构

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动方式

### 命令行模式

```bash
python profit_core.py
```

默认读取当前目录下的 `咔咔唛.xlsx`（订单表）和 `24日成本表.xlsx`（成本表），输出到 `output/` 目录。

支持日期筛选：

```bash
python profit_core.py 2026-05-11 2026-05-24
```

### GUI 模式

```bash
python main.py
```

启动后：
1. 点击"选择"按钮，选择订单表、成本表和输出目录
2. 可选填写开始日期和结束日期（格式：YYYY-MM-DD，不填则统计全部数据）
3. 点击"开始计算"
4. 查看运行日志，计算完成后弹窗提示输出文件路径

## 输入文件要求

### 订单表
必须包含以下字段（字段名支持模糊匹配）：
- **商品ID** — 商品编号
- **商家编码** — 用于匹配成本的编码（SKU/规格编码）
- **商品数量** — 下单数量
- **订单提交时间** — 订单提交时间（用于时间筛选）
- **商家收入** — 商家实际收入金额
- 订单号（可选）— 主订单号/子订单号

### 成本表
必须包含以下字段（字段名支持模糊匹配）：
- **编码列** — 商家编码/商品编码/商品名称/品名等
- **成本列** — 成本/成本价/单价/金额等

## 输出文件说明

输出 Excel 包含 4 个 Sheet：

### Sheet1：商品ID编码明细
按 商品ID + 商家编码 汇总的利润明细：
- 商品ID、商家编码、成本单价、编码对应订单行数
- 编码对应商品数量、编码对应总成本、编码对应总收入
- 编码对应总利润、ID对应总利润、状态

### Sheet2：商品ID汇总
按 商品ID 汇总的利润统计：
- 商品ID、订单行数、商品数量合计
- 总收入、总成本、总利润
- 异常编码数量、异常订单行数

### Sheet3：异常明细
不参与利润计算的异常数据：
- 异常类型、商品ID、商家编码、商品数量
- 商家收入、订单提交时间、订单号、原因

### Sheet4：成本表快照
成本表的处理结果快照：
- 商家编码、成本单价、状态、原因
- 状态包括：正常、成本重复、编码为空、成本异常

## 异常说明

以下情况的数据不参与利润计算，进入异常明细：

| 异常类型 | 说明 |
|---------|------|
| 商家编码为空 | 订单表中商家编码为空或为无效值（-、--、nan 等） |
| 商品数量异常 | 商品数量为空、无法转数字或小于等于 0 |
| 商家收入异常 | 商家收入为空或无法转数字 |
| 成本缺失 | 商家编码在成本表中未找到 |
| 成本重复 | 成本表中同一编码对应多个不同成本金额 |

## 数据清洗

工具自动处理以下情况：
- 前后空格
- 制表符（\t）
- 空值、-、--、nan、NaN、None
- 金额中的逗号和人民币符号（￥）
- 字符串数字自动转换
- 日期字段自动转 datetime
- 商品ID和商家编码保留为字符串（防止科学计数法）
